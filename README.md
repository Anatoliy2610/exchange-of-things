### Платформа для обмена вещами
<p>Веб приложение о размещении объявления о товарах для обмена, просматривать чужие объявления и отправлять предложения на обмен. Приложение позволяет просматривать, изменять, добавлять или удалять объявления о товарах, а также категорию и качество товара; предложения об обмене и статусе предложения.</р>

##### Установить проект себе можно, прописав команды в командной строке:
- `git clone https://github.com/Anatoliy2610/exchange-of-things.git`
- `pip install -r requirements.txt` *установить зависимости*
- `make migrate` *выполняются миграции*

##### Запустить проект можно, прописав команды в командной строке:
- `make run`

*В проект автоматически подгружаются статусы предложений, категория и качество товара для объявления. В случае неоходимости, можно их расширить.*

##### Запустить проверки проекта можно, прописав команды в командной строке:
- `make test` запускает тестирование

##### В проекте используются маршруты:
- `/` *главная страница со всеми объявлениями о товаре*
- - `/ads_id/create/` *создание объявления*
- - `/ads_id/update/` *изменение объявления*
- - `/ads_id/delete/` *удаление объявления*
- - `/ad_id/` *просмотр конкретного объявления о товаре*
- `/category/` *страница со всеми категориями товара*
- - `/category/category_id/create/` *создание категории*
- - `/category/category_id/update/` *изменение категории*
- - `/category/category_id/delete/` *удаление категории*
- `/condition/` *страница со всеми критериями качествами товара*
- - `/condition/condition_id/create/` *создание качества товара*
- - `/condition/condition_id/update/` *изменение качества товара*
- - `/condition/condition_id/delete/` *удаление качества товара*
- `/status/` *страница со всеми статусами предложений*
- - `/status/status_id/create/` *создание статуса*
- - `/status/status_id/update/` *изменение статуса*
- - `/status/status_id/delete/` *удаление статуса*
- `/users/` *страница со всеми пользователями приложения*
- - `/users/user_id/create/` *регистрация пользователя*
- - `/users/user_id/update/` *изменение пользователя*
- - `/users/user_id/delete/` *удаление пользователя*
- - `/users/login/` *аутентификация пользователя*
- - `/users/logout/` *выход из системы*
- `/proposal/` *страница со всеми предложениями об обмене товара*
- - `/proposal/proposal_id/create/` *создание предложения*
- - `/proposal/proposal_id/update/` *изменение предложения*
- - `/proposal/proposal_id/delete/` *удаление предложения*
- - `/proposal/proposal_id/` *просмотр конкретного предложения о товаре*
